## Selected Projects

### Mini Agent Tool-Use Benchmark

Built a small-scale benchmark for evaluating LLM agent behavior in controlled tool-use tasks. The project focuses on success rate, wall-clock latency, tool-call latency, invalid tool calls, retries, token usage, cost estimation, and simple guardrail violations.

This project is intended as a compact proof-of-work for LLM agent systems, tool-use evaluation, agent benchmarking, and safety-oriented diagnostics.

### LOB Representation Diagnostic

Built an independent diagnostic project for studying the relationship between representation learning and downstream prediction on limit order book data.

The project emphasizes chronological-vs-random split comparison, leakage-aware evaluation, reconstruction representation analysis, and mid-price trend prediction diagnostics. It is designed as a focused proof-of-work for financial ML, representation diagnostics, and ML for decision-making.

### Cell Segmentation Robustness Diagnostic

Built a small diagnostic benchmark for microscopy cell instance segmentation. The project focuses on evaluating out-of-the-box and supervised robustness under practical image-segmentation settings.

This project is positioned as evidence of benchmark construction, model evaluation, failure-case analysis, and reproducible experiment documentation rather than as a full biomedical AI research contribution.

### NIPT Timing Optimization and Aneuploidy Screening

Built a multi-stage modeling pipeline covering feature preprocessing, segmented polynomial regression, BMI-based timing optimization, and chromosome aneuploidy classification.

The project used GA-DP, NSGA-DP, XGBoost, SMOTE, class weighting, PR/ROC analysis, and SHAP-based interpretability. It demonstrates modeling, optimization, imbalanced classification, and technical writing ability.

### GPU-Accelerated CFAR and MVDR Operators

Developed OpenCL-based GPU-parallelized operators for maritime radar signal processing. Work included CFAR pipeline optimization, memory-layout adaptation, workload tiling, and latency reduction for small-input real-time processing scenarios.

### ROS 2 / Gazebo Autonomous Lunar Rover System

Developed ROS 2 modules in Gazebo for autonomous navigation, sensor integration, sample collection, and return-to-base task execution. The system combined vision-based object recognition, mmWave radar perception, obstacle handling, and task-level path planning.
