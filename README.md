## Selected Projects

### [mini-agent-tooluse-benchmark](https://github.com/GoldenSection0618/mini-agent-tooluse-benchmark)

A compact benchmark for evaluating LLM agent behavior in controlled tool-use tasks.

Focus: success rate, wall-clock latency, tool-call latency, invalid tool calls, retries, token usage, cost estimation, and simple guardrail violations.

Positioning: proof-of-work for LLM agent systems, tool-use evaluation, agent benchmarking, and safety-oriented diagnostics.

---

### NIPT Timing Optimization and Aneuploidy Screening

Built a multi-stage modeling pipeline for Non-Invasive Prenatal Testing (NIPT), covering feature preprocessing, segmented polynomial regression, BMI-based timing optimization, and chromosome aneuploidy classification.

Methods: GA-DP, NSGA-DP, XGBoost, SMOTE, class weighting, PR/ROC analysis, and SHAP-based interpretability.

Positioning: proof-of-work for medical AI, interpretable clinical data modeling, imbalanced classification, optimization, and structured technical writing.

---

### [cellseg-robustness-diagnostic](https://github.com/GoldenSection0618/cellseg-robustness-diagnostic)

A small diagnostic benchmark for microscopy cell instance segmentation.

Focus: out-of-the-box and supervised robustness evaluation, segmentation baseline comparison, failure-case inspection, and reproducible experiment documentation.

Positioning: proof-of-work for biomedical image analysis, ML robustness diagnostics, benchmark construction, and model evaluation.

---

### [lob-representation-diagnostic](https://github.com/GoldenSection0618/lob-representation-diagnostic)

An independent diagnostic project for studying the relationship between representation learning and downstream prediction on limit order book data.

Focus: chronological-vs-random split comparison, leakage-aware evaluation, reconstruction representation analysis, and mid-price trend prediction diagnostics.

Positioning: proof-of-work for financial ML, representation diagnostics, and ML for decision-making.

---

### [HGSFusion Reproduction and Runtime Diagnostics](https://github.com/GoldenSection0618/HGSFusion)

A traceable reproduction and diagnostics project for learning-based radar-camera fusion.

Focus: environment setup, dependency repair, data-contract checking, checkpoint evaluation, small-scale training dry-runs, and runtime bottleneck analysis.

Positioning: evidence of reproducibility engineering, experimental boundary documentation, and debugging ability in learning-based perception systems.

---

### GPU-Accelerated CFAR and MVDR Operators

Developed OpenCL-based GPU-parallelized operators for maritime radar signal processing.

Focus: CFAR pipeline optimization, memory-layout adaptation, workload tiling, and latency reduction for small-input real-time processing scenarios.

Positioning: evidence of systems-level implementation, performance debugging, and GPU-aware signal-processing optimization.

---

### ROS 2 / Gazebo Autonomous Lunar Rover System

Developed ROS 2 modules in Gazebo for autonomous navigation, sensor integration, sample collection, and return-to-base task execution.

Focus: vision-based object recognition, mmWave radar perception, obstacle handling, greedy path planning, and simulation-based task validation.

Positioning: evidence of robotics simulation, perception integration, and task-level engineering coordination.
