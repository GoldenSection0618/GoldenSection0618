## Selected Projects

### [mini-agent-tooluse-benchmark](https://github.com/GoldenSection0618/mini-agent-tooluse-benchmark)

A compact benchmark for evaluating LLM agent behavior in controlled tool-use tasks, including success rate, latency, invalid tool calls, retries, token usage, cost estimation, and simple guardrail violations.

### NIPT Timing Optimization and Aneuploidy Screening

Built a multi-stage modeling pipeline for Non-Invasive Prenatal Testing (NIPT), covering feature preprocessing, segmented polynomial regression, BMI-based timing optimization, and chromosome aneuploidy classification.

Methods: GA-DP, NSGA-DP, XGBoost, SMOTE, class weighting, PR/ROC analysis, and SHAP-based interpretability.

### [cellseg-robustness-diagnostic](https://github.com/GoldenSection0618/cellseg-robustness-diagnostic)

A small diagnostic benchmark for microscopy cell instance segmentation, focusing on segmentation baseline comparison, robustness evaluation, failure-case inspection, and reproducible experiment documentation.

### [lob-representation-diagnostic](https://github.com/GoldenSection0618/lob-representation-diagnostic)

An independent diagnostic project studying the relationship between representation learning and downstream prediction on limit order book data, with emphasis on chronological evaluation and leakage-aware diagnostics.

### [HGSFusion Reproduction and Runtime Diagnostics](https://github.com/GoldenSection0618/HGSFusion)

A traceable reproduction and diagnostics project for learning-based radar-camera fusion, covering environment repair, data-contract checking, checkpoint evaluation, training dry-runs, and runtime bottleneck analysis.
